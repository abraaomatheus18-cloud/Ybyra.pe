# Ybyra.pe

Plataforma inteligente de gestão de obras públicas para a Secretaria de Obras de Olinda — IA, BI, análise preditiva e georreferenciamento.

## Como rodar

É uma aplicação de página única (single file). Basta abrir o `index.html` em qualquer navegador — não há dependências de build nem servidor.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub e envie este conteúdo.
2. Em **Settings → Pages**, selecione a branch `main` e a pasta raiz (`/`).
3. O site ficará disponível em `https://<seu-usuario>.github.io/<nome-do-repo>/`.
